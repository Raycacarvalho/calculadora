# Ciclo DevOps Aplicado ao Projeto Calculadora

## 1. Planejamento (Plan)

O projeto foi planejado para desenvolver uma calculadora com operações matemáticas básicas e operação de potência. Foram definidas as funcionalidades do sistema e a divisão das atividades entre os integrantes da equipe.

## 2. Desenvolvimento (Code)

O desenvolvimento foi realizado utilizando HTML, CSS e JavaScript no frontend e Python no backend. O código foi organizado em arquivos e pastas, como `index.html`, `style.css`, `script.js` e a pasta `backend`.

O Git e o GitHub foram utilizados para controlar as versões do código e permitir o trabalho colaborativo entre os integrantes.

## 3. Build

O projeto foi organizado para integrar o frontend com o backend. As dependências do backend foram registradas no arquivo `requirements.txt`.

## 4. Testes (Test)

Foram realizados testes das operações da calculadora para verificar se os resultados estavam corretos e se a comunicação entre frontend e backend funcionava adequadamente.

## 5. Release

Após as funcionalidades serem desenvolvidas e testadas, as alterações foram registradas utilizando commits no Git. As branches foram utilizadas para organizar o desenvolvimento das funcionalidades.

## 6. Deploy

O código do projeto foi armazenado no GitHub, permitindo que a versão desenvolvida fique disponível no repositório para a equipe.

## 7. Operação (Operate)

A equipe pode continuar realizando alterações, correções e melhorias no sistema utilizando o fluxo de branches e commits.

## 8. Monitoramento (Monitor)

O histórico de commits e as branches do GitHub permitem acompanhar as alterações realizadas no projeto e identificar a evolução do desenvolvimento.

## Conclusão

O ciclo DevOps foi aplicado ao projeto por meio do planejamento das funcionalidades, desenvolvimento colaborativo, testes, controle de versões com Git e GitHub, organização por branches e acompanhamento das alterações realizadas pela equipe.
